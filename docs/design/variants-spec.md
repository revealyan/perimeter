## Варианты

### A · «Спокойная лента» — эволюция трёхпанельного
Идея: лента читается как документ; шаги агента свёрнуты в одну сводку; внимание — только на запрос разрешения.
- Тёплая тёмная тема (база текущего клиента), шрифт Inter, акцент терракота `#d4805f`.
- Сайдбар 260 · лента колонкой 720 по центру · правая панель 300 (контекст, изменения, сессия, ход).
- Пикеры аккаунт·модель и режим — внутри композера (как в Claude Desktop), шапка — только имя и статус.
Референсы: Claude Code Desktop, Zed agent panel.

### B · «Пульт» — внимание к параллельным сессиям
Идея: главный вопрос «кто меня ждёт?». Сайдбар группирует сессии по статусу, ждущие — сверху с ответом прямо из списка.
- Холодная графитовая тема, Inter, акцент индиго `#7c8cff`.
- Узкая полоса проектов 56 · список сессий 320 по статусам («Ждут тебя · 2», «Работают · 1», «Готовы · 1», «Остыли · 1») · лента.
- Правой панели нет: контекст и изменения — компактные чипы в шапке, раскрываются поповером.
- Карточка «ждёт тебя» в списке: вопрос/команда + кнопки «Разрешить/Открыть».
Референсы: Conductor, Cursor 3 (сайдбар агентов), Linear (инбокс).

### C · «Ревью» — изменения в центре внимания
Идея: агент меняет код — значит главное ревью правок. Лента уже, справа большая панель с вкладками «Изменения · Контекст · План».
- Светлая тема, IBM Plex Sans + IBM Plex Mono, акцент терракота `#c2603e`.
- Сайдбар 240 · лента 520 · панель ревью ~680: список файлов + полный диф с номерами строк.
- Запрос разрешения правки показывается диффом прямо в панели ревью.
Референсы: Codex app (review pane), Cursor review, GitHub PR.

### D · «Терминал» — плотный, клавиатурный
Идея: для тех, кто живёт в tmux. Моноширинный шрифт, вкладки сессий сверху, строка статуса снизу, ответы клавишами.
- Почти чёрная тема с зеленоватым оттенком, JetBrains Mono, акцент янтарь `#e0a458`.
- Вкладки сессий (статус-глиф) · лента блоками с гуттером статуса · строка статуса (среда, ssh, контекст, $, модель).
- Разрешение — строка-промпт: `[y] разрешить  [n] отклонить  [a] всегда`. Ctrl+K — палитра команд.
Референсы: Warp (блоки), Claude Squad / tmux, Ghostty.
