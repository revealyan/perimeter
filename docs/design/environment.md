# «Окружение» — среды, движок, сервисы (сводка решений владельца, 19–22.11; сверено с кодом 23.11)

Заметки владельца с локальной разработки, перенесены как есть; `Статус 23.11` — что изменилось или уже есть.

## 1. Страница «Окружение» (Настройки → Окружение)

- Две колонки: «Этот компьютер» и каждый VPS — у сред свои инструменты.
- Строки: Claude Code (движок), git, docker, python+gcc, Chrome/Edge, Node.
- Для каждой: версия/есть-нет · на что влияет отсутствие · кнопка «как поставить/обновить».
- **Этот компьютер — инструкция, не автоустановка:** это не наши пакеты, чужую систему молча не ломаем.
- **VPS-колонка = диагностика до установки:** что установщик доустановит сам. Сервер отдан под Perimeter,
  поэтому там ставим сами — но только показав план и по одной кнопке (см. `onboarding.md`).
- Механика: один запрос `env.probe` на supervisor'е (одинаковый код для обеих сред).
- Git в системе: без него просто нет git-фич (статус в «Файлах», перенос правок патчем, worktree воркеров) —
  подписать в строке.
- Сюда же: ssh-ключи среды (показать/скопировать публичный, сгенерировать, `ssh -T git@github.com`).

`Статус 23.11:` нет. Ближайшее — проверка пакетов в установщике (`packages_missing`: git/xvfb/gcc/make/python3).

## 2. Обновление движка Claude Code (отдельный слой, не с версиями приложения)

- Хранение: `cli/<версия>/` + `cli/current` → N (как версии сервера на VPS; локально — та же схема в профиле).
- Supervisor запускает CLI по пути current (SDK: `pathToClaudeCodeExecutable`).
- Оболочка проверяет свежесть (npm registry, один HTTP-запрос, без установки):
  «движок 2.1.319 · доступна 2.1.34» + кнопка «Обновить движок».
- Каналы: стабильный (по умолчанию — только версии, проверенные нашим релизом/CI) и fresh (последний с npm,
  пометка «непроверено», тумблер в настройках).
- Докачка в соседнюю папку — идущие сессии не замечают; откат кнопкой на прошлую версию.

`Статус 23.11:` путь к CLI уже явный (`PERIMETER_CLI_PATH` → `pathToClaudeCodeExecutable`). Мини-npm докачки
(`local-server.mjs`) с 23.11 качает потоком с прогрессом, таймаутом зависания, повторами и пометками
поставленных пакетов — готовая основа для «Обновить движок». Проверено на настоящем npm: 153 МБ за 4 с.

## 3. Сервисы среды (docker)

- Долгоживущие инстансы на уровне СРЕДЫ (ПК/VPS), не в проекте: postgres-16, redis…
- У каждого: порт из нашего диапазона, том (данные переживают пересоздание), пароль в хранилище среды
  (как ключи аккаунтов), статус, старт/стоп.
- Нужна другая версия БД — второй сервис рядом на другом порту (postgres-14 + postgres-16), проект
  подключается к нужному. Per-project compose — исключение: агент сам пишет compose.yaml в папку проекта,
  когда задаче реально нужна одноразовая база (не запрещаем).
- Порты сервисов автоматически попадают в панель «Порты» с автопробросом.

`Статус 23.11:` нет. На VPS docker — rootless под пользователем службы (решение 23.11, `onboarding.md`).

## 4. Переменные проекта

- У проекта поле «переменные окружения» (шифрованно).
- Подключить сервис = одна строка: `DATABASE_URL=postgres://…@<сервис>/<база>`.
- Supervisor отдаёт их в env процессов сессий проекта — агент сразу видит переменные, docker ему знать
  не нужно (90% случаев).
- Закрывает пункт гэп-анализа «переменные окружения проекта/среды (шифрованно)».

## 5. Агент и среды

- (Опционально) MCP-инструмент `env.service.*`: поднять/лист/стоп сервисов среды прямо из хода —
  «дорогой решает, механика дешёвая делает».
- Связка: среда → сервисы → переменные проекта → сессии.

## 6. Рядом (локальная среда)

- Локальный supervisor должен переживать закрытие окна (сейчас умирает вместе с Electron: бандл в resources,
  движок в профиле, запуск под Node Electron). Варианты: отсоединяться при выходе / трей вместо выхода /
  фоновая служба Windows.
- Ретрай портов: после EADDRINUSE (8791/8800) туннель и supervisor не поднимаются сами до перезапуска
  приложения — ретрай с паузой, в перспективе автоподбор порта.

`Статус 23.11:` оба пункта актуальны (`index.mjs`: `window-all-closed` → `stopLocalSupervisor`). Проброс портов
превью при занятом порте уже берёт свободный; туннель supervisor'а и `:8791` — нет.
