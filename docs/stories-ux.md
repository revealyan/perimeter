# Стори UX-раунда (полный объём, 11 пунктов)

Каждая стори — вертикальный срез protocol → supervisor → desktop. Порядок = порядок исполнения.

## S1. Бэкенд-присест: проекты, настройки сессии, контекст
- `~/.perimeter/projects.json`: {id, name, path, profile?, model?, permissionMode?} + CRUD
- protocol: `cmd:project.list/new/rename/delete`, `ProjectInfo[]` в `event:hello`; сессия получает `projectId` (по cwd проекта или явно)
- protocol: `cmd:session.settings {sessionId, model?, permissionMode?, effort?, profile?}`:
  - model/effort/режим → на лету (SDK `setModel`/`setPermissionMode`)
  - profile → только из idle/dead (иначе err BUSY): respawn с env нового профиля, тот же claudeSessionId
- protocol: `cmd:session.context {sessionId}` → `getContextUsage` → ack {window, used%, cache, limits}
- тесты: проекты CRUD, settings (модель на лету/профиль между ходами), context ack

## S2. Сайдбар: проекты
- секции проектов (имя, путь, счётчик), «+» у проекта = сессия с дефолтами проекта
- секция «Без проекта»
- кнопка «Создать…» → диалог: имя/проект(папка)/профиль/модель/режим; создание проекта там же (выбор пути на VPS)
- переименование сессии (cmd:session.rename → /rename), drag сессии между проектами — потом

## S3. Шапка сессии: пикер «аккаунт · модель» + режим/effort
- пикер как в Desktop: меню группами по аккаунтам, внутри — модели; текущее — «zai · glm-5.3[1m]»
- смена модели — мгновенно; смена аккаунта — подтверждение «ход продолжится другим аккаунтом» (между ходами)
- селекторы режима разрешений (Manual/Plan/AcceptEdits/Auto) и effort

## S4. Картинки туда-обратно
- композер: Ctrl+V (буфер/скриншот), drag&drop, «+» → чипы-превью с крестиком; отправка → base64 `images[]`
- лента: юзер-баббл с картинками; tool_result с image-блоками → рендер
- main-процесс: нативный буфер через IPC (nativeImage → PNG buffer)

## S5. Диф-вью правок
- карточка Edit/Write: «показать диф» → панель с построчным дифом (свой мини-алгоритм, без зависимостей)
- счётчик за ход «+N −M» в шапке ленты/правой панели; копировать диф

## S6. Контекст-ринг
- правая панель: кольцо % окна, подписи (токены, кэш тёплый/холодный, до лимита)
- опрос `cmd:session.context` раз в 20 с для активной сессии + после каждого хода

## S7. Полировка ленты и карточек
- типографика (размерная сетка, межстрочка, ширина колонки), код-блоки с подсветкой имён файлов
- карточки: «скопировать», свёртка вывода, статус-чипы, иконки инструментов
- пустые состояния ленты, scroll-to-bottom чип, разделители дней

## S8. Уведомления, трей, автозапуск
- OS-тосты: «ход завершен» (окно не в фокусе), «ждёт разрешения» (срочно)
- трей: иконка, бейдж «!» при карточке разрешения, «показать/выход»
- настройка «запускать с системой» (electron autoupstart — опционально)

## S9. Состояния соединения и сессии
- плашки: «переподключение…», «ресинк из транскрипта…», «сессия остывает (idle → dead)» без слова «мертва»
- при dead: подсказка «напишите что-нибудь — поднимется с историей»
