# Смок perimeter — все фичи списком

Чек-лист ручного прохода перед выкаткой и после неё. Каждый пункт: **что сделать → что должно быть**.
Номера (А1, Б3…) — чтобы сообщать «упал Ж4», не пересказывая.

Где проверять (метка в конце пункта):
- **[стенд]** — браузерный стенд без токенов: renderer :5174 + демо-supervisor'ы (:8795 «VPS», :8796 «этот компьютер», :8797 «VPS 2»), `.claude/launch.json`. Демо-движок отвечает сценариями по словам в сообщении: «разреш», «вопрос», «ошибк», «картин», «субагент», «долго».
- **[прил]** — приложение Electron (`npm run dev:electron -w @perimeter/desktop`): ssh-туннели, локальный supervisor, уведомления, проброс портов, системные диалоги.
- **[прод]** — настоящий supervisor на VPS с настоящим claude (тратит токены).

Без метки — работает и на стенде, и в приложении.

## А. Подключения (как в Happy)

- [ ] А1 Первый запуск → в сайдбаре секции подключений: VPS (одна или несколько) и «Этот компьютер» последним.
- [ ] А2 «+ Подключение» внизу сайдбара → открываются Настройки на «Новое подключение».
- [ ] А3 Форма VPS: имя, хост, ssh-порт, пользователь, порт supervisor'а, ключ (кнопка выбора файла) → «Проверить» показывает понятный результат (ok / текст ошибки без «Error invoking remote method»). [прил]
- [ ] А4 «Подключить» → подключение появилось в списке настроек и отдельной секцией в сайдбаре, точка статуса зелёная. [стенд: имя + ws-адрес]
- [ ] А5 Флажок «включено» выкл → секция пропадает, соединения нет; вкл → вернулась и подключилась.
- [ ] А6 «удалить подключение» → спрашивает подтверждение → пропадает из настроек и сайдбара, его кэш стирается.
- [ ] А7 Правка хоста/порта существующего подключения → переподключение без перезапуска приложения. [прил]
- [ ] А8 «Этот компьютер»: включить/выключить, «Перезапустить» → локальный supervisor поднимается (статус «запущен»), при выходе из приложения гасится. [прил]
- [ ] А9 Выключенный «Этот компьютер» → внизу сайдбара строка «выключен · включить».
- [ ] А10 Старый `~/.perimeter-client/tunnel.json` без `connections.json` → при старте переезжает в подключение «VPS» с тем же локальным портом 8790. [прил]
- [ ] А11 Шапка секции VPS: «ssh ✓» при живом туннеле, «ssh <статус>» при проблеме, «напрямую» на стенде; у «Этого компьютера» — порт.

- [ ] Б2 Без связи с подключением карточка в «Ждут тебя» неактивна, с пояснением «ответить можно после переподключения».
- [ ] Б3 Шапка секции: свернуть/развернуть (запоминается), по наведению — «+ сессия» и «+ проект» именно в этом подключении.
- [ ] Б4 Наверху: «Новый проект» и «Новая сессия» (Ctrl+N) — отдельные кнопки; при узком окне заголовок «Все проекты» не обрезан.
- [ ] Б5 Внутри секции сессии сгруппированы по проектам; группа сворачивается; «+» у группы — новая сессия в этом проекте.
- [ ] Б6 Поиск по сессиям (лупа) фильтрует по имени.
- [ ] Б7 Фильтр «Все проекты ▾» → выбор проекта сужает список во всех подключениях.
- [ ] Б8 Архив внизу: «Архив · N», раскрывается; меню строки «В архив» / «Вернуть из архива».
- [ ] Б9 Меню строки (⋯): «Переименовать», «Форк — копия истории» (новая сессия с той же историей), «Остановить процесс» (сессия → «остыла»), «Перенести в другое подключение» — выключено с подсказкой.
- [ ] Б10 Плашка синка в секции: «Из «…»: N проектов без папки здесь» → «Привязать» открывает диалог синка (А↔ своя папка, «не предлагать»). [стенд: VPS ↔ этот компьютер]
- [ ] Б11 Подключение без связи → строка «нет связи — сессии на сервере продолжают работать · повторить».
- [ ] Б12 Пустое подключение → «Сессий нет. Создать — она будет жить на сервере / на этом компьютере».

## В. Новая сессия (черновик в центре, без окна)

- [ ] В1 Ctrl+N / «+» → в центре черновик: подключение, проект, аккаунт·модель, усилие, ultracode, режим разрешений.
- [ ] В2 Первое сообщение создаёт сессию; имя — из первой строки сообщения; сообщение не пропадает из ленты.
- [ ] В3 Выбор (подключение, проект, модель…) запоминается на подключение — следующий черновик открывается с ним.
- [ ] В4 Открыл другую сессию — черновик закрылся; текст черновика сохранился и вернулся при новом Ctrl+N.

## Г. Новый проект

- [ ] Г1 «Новый проект» → вкладки «Пустой / Из git / Готовая папка».
- [ ] Г2 Название → папка латиницей (транслит) под названием; «Изменить» — своё имя папки с проверкой.
- [ ] Г3 «Где создать» — галочки по всем подключениям на связи; у каждого — путь в хранилище и чип плана: создам папку / склонирую / подключу (совпал origin) / занято чужим / папки нет. Подсказка «В обеих средах» / «Во всех выбранных средах» по числу галочек.
- [ ] Г4 «Из git»: ссылка → имя из репозитория; клон без запроса пароля (приватный — только с доступом пользователя сервиса), ошибка понятная, токен в ссылке замаскирован. [прод]
- [ ] Г5 «Дополнительно» → своя папка вместо хранилища.
- [ ] Г6 «Создать проект» → проект появился группой в сайдбаре каждого выбранного подключения.

## Д. Лента и ход

- [ ] Д1 Отправка → печать ответа по мере генерации, без дёрганий; маркдаун: абзацы, списки, таблицы, код с подсветкой и «копировать», ссылки только http/https/mailto.
- [ ] Д2 Шаги хода свёрнуты в «N шагов · M файлов изменено +X −Y»; раскрываются; строки — тип инструмента и цель.
- [ ] Д3 Карточки инструментов: команда (stdout/stderr), чтение файла (с подсветкой), поиск/список файлов, правка — диф с номерами строк, запись, картинка.
- [ ] Д4 Диф в ленте: «Построчно / Рядом / Мутации» (подсветка изменённых слов); «в Изменениях →» открывает файл в панели.
- [ ] Д5 Картинки: свои (из поля ввода) — превью; прочитанные агентом — видны в живой ленте; в подгруженной истории — пометка «картинка · N КБ». [стенд: «картин»]
- [ ] Д6 Субагенты: старт/конец видны в ленте. [стенд: «субагент»]
- [ ] Д7 «Стоп» / Esc во время хода → ход прерван, недопечатанный текст не висит «призраком», итог «Ход прерван».
- [ ] Д8 Итог хода: стоимость сессии, число ходов, длительность.
- [ ] Д9 Ошибка API → блок с объяснением (z.ai 1113 «ключ не от кодинг-плана», 401, 429, 529, 5xx, оплата, нет модели). [стенд: «ошибк»]
- [ ] Д10 Повтор запроса → строка «запрос не прошёл (429) · повтор 3 из 10 через 8 с», пропадает после ответа. [прод]
- [ ] Д11 Автоскролл: прилипает, только если был внизу; при чтении выше — кнопка «к последнему».
- [ ] Д12 История открытой сессии подгружается при открытии (не все разом); долгая сессия открывается без ложных таймаутов. [прил/прод]
- [ ] Д13 Обрыв связи → плашка «переподключение… · повторить»; после возврата лента догоняет пропущенное без дублей.

## Е. Разрешения и вопросы

- [ ] Е1 Запрос разрешения → карточка в ленте и в «Ждут тебя»: «Разрешить / Запретить / Всегда для <инструмент>». [стенд: «разреш»]
- [ ] Е2 Клавиши Y / N / A отвечают на карточку (и в русской раскладке).
- [ ] Е3 «Всегда для …» → следующий такой же вызов проходит без вопроса.
- [ ] Е4 Вопрос агента: все вопросы, варианты, мультивыбор, «Свой вариант…», стрелки ←/→ по вариантам. [стенд: «вопрос»]
- [ ] Е5 Окно не в фокусе → системное уведомление «ждёт разрешения: …» / «агент задал вопрос» / «ход завершён». [прил]
- [ ] Е6 Перезапуск клиента при висящем разрешении → карточка приходит снова и на неё можно ответить.

## Ж. Поле ввода

- [ ] Ж1 Вид из настроек: «Карточка» (Enter — отправить, Shift+Enter — строка) или «Панель с ручкой» (Enter — строка, Ctrl+Enter — отправить); Ctrl+Enter отправляет в обоих.
- [ ] Ж2 Панель: высота тянется за ручку и с клавиатуры (↑/↓, Home — по умолчанию), запоминается.
- [ ] Ж3 Черновик на каждую сессию переживает переключение сессий и перезапуск; после отправки не возвращается.
- [ ] Ж4 Отправка не удалась → текст остался в поле.
- [ ] Ж5 Картинка: Ctrl+V / перетаскивание / скрепка → превью до отправки, удаляется крестиком.
- [ ] Ж6 Выбор «аккаунт · модель»: модели всех аккаунтов подключения, «Своя модель» (ввести имя вручную); скрытые в настройках — в «Другие модели ▸»; текущая модель всегда на виду.
- [ ] Ж7 Усилие — только если у модели оно есть (у GLM нет); ultracode — только если аккаунту разрешён; режим разрешений — 4 варианта.
- [ ] Ж8 Смена аккаунта во время хода → понятный отказ «только между ходами».

## З. Шапка и строка статуса

- [ ] З1 Шапка: проект / имя сессии / бейдж состояния (создаётся, запускается, готова, работает, ждёт разрешения, ждёт ответа, остановлена, ошибка, остыла); иконки панелей; «Перенести» — выключено с подсказкой.
- [ ] З2 Строка статуса: подключение + канал (ssh ✓ / напрямую / локально), число проброшенных портов (клик → «Порты»), ctx % с полоской (клик → «Контекст»), +/− изменений (клик → «Изменения»), стоимость, модель, режим, версия supervisor'а, «тёплых N/M», шестерёнка настроек (Ctrl+,).

## И. Панель

- [ ] И1 Вкладки: Изменения, Терминал, Файлы, Браузер, Порты, Задачи, Контекст; не влезшие — в «⋯».
- [ ] И2 Клавиши: Ctrl+Shift+D/E/B/T — вкладки, Ctrl+` — терминал, Ctrl+\ — показать/скрыть, Ctrl+Shift+F — на весь экран, Esc — выйти из полного экрана.
- [ ] И3 Положение: справа / снизу / слева / плавающая (тянется за шапку, прилипает к краям, двойной клик — обратно); край тянется, двойной клик по краю — размер по умолчанию.
- [ ] И4 **Изменения**: список файлов с +/−, диф трёх видов, «показать в ленте».
- [ ] И5 **Файлы**: дерево папки сессии, поиск по имени, просмотр с подсветкой, git-отметки, отметки правок агента по строкам, «Упомянуть в сообщении» (@путь в поле ввода), «Открыть в VS Code» (локально — файл; у VPS — Remote SSH на хост этого подключения). Выйти за папку сессии нельзя.
- [ ] И6 **Терминал**: открывается в папке сессии нужного подключения, ввод/вывод, ресайз, после переподключения поток продолжается; идущие команды агента — карточками. [на VPS — node-pty]
- [ ] И7 **Браузер → Превью здесь**: адрес или порт; чипы портов dev-серверов; у VPS порт пробрасывается по ssh (чип «VPS → туннель :PORT», ошибка — «повторить»); Десктоп/Телефон; назад/вперёд/обновить; «во внешнем браузере».
- [ ] И8 **Браузер → Браузер на сервере** (только у VPS): «Запустить браузер на сервере» → картинка; адрес или поиск (DuckDuckGo); клик, прокрутка, клавиатура, вставка Ctrl+V; назад/вперёд/обновить/стоп; «■» закрывает (освобождает память VPS). [прод для VPS; на стенде — локальный Chrome]
- [ ] И9 Браузер на сервере: закрыть и открыть панель → тот же браузер подхватился; обрыв связи → после возврата картинка идёт дальше; задержка не копится (медленный канал — ~1 кадр/с, но без отставания на десятки секунд).
- [ ] И10 Браузер на сервере: войти на сайт (например, Фигма), закрыть браузер «■», открыть снова → вход сохранился. [прод]
- [ ] И11 **Порты**: на виду проброшенные, dev-серверы и всё от 1024; системные — «Ещё портов: N»; «Пробросить» / снять (крестик), ручной проброс по номеру; адрес «localhost:PORT» открывает во внешнем браузере, глобус — во вкладке «Браузер». [проброс — прил]
- [ ] И12 Автопроброс (флажок в «Портах», по умолчанию вкл): запустить dev-сервер на VPS → через ≤8 с порт проброшен с отметкой «авто»; снятый руками порт больше не пробрасывается. [прил]
- [ ] И13 **Задачи**: план агента из TodoWrite, статусы пунктов.
- [ ] И14 **Контекст**: кольцо % окна, токены, категории; обновляется во время работы.
