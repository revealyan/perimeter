## Открытые развилки

| Развилка | Блокирует | Когда решать |
|---|---|---|
| Термин-панель (свой PTY-обзор vs только лента) | UI P2 | на срезе P2 |
| Показ фоновых работ/`backgroundTasks` | UI P1–P2 | на разборе P1 |
| Диф-вью + чекпоинты (rewindFiles) — состав P2 | UI P2 | на срезе P2 |
| Аккаунты из UI: типы и готовые шаблоны в «Добавить» (подписка Claude / ключ Anthropic / шлюз: z.ai и др.) | UI добавления аккаунта | следующая развилка цикла «аккаунты из UI» |
| Аккаунты из UI: удаление — что с его сессиями и папкой | ничего (v1 без удаления или с запретом при живых сессиях) | после первого среза аккаунтов |
| Аккаунты из UI: один аккаунт сразу в нескольких подключениях | ничего | после первого среза аккаунтов |
| Системные пакеты сервера (Chromium, Xvfb, git): ставит ли установщик их сам под root | установку на голый сервер | после первой живой установки на новый сервер |
| MCP: проектный уровень (.mcp.json проекта) из UI | ничего | после отзыва владельца о MCP аккаунта |
| Другие агенты как типы аккаунтов (Codex и т. п.) | ничего | позже; сейчас только подписка Claude и ключ API с шаблонами (владелец) |
