# Бэклог

Единый список задач. Решения и история — в `decisions.md`, кандидаты из референсов — в `gap-analysis.md`
(топ-9 и «быстрые S»). Сделанное отсюда убирается, в журнал решений — запись.

## Сейчас (порядок владельца, 2026-11-23)

1. **Ризонинг пропадает после переподключения.** Claude Code пишет thinking Anthropic-моделей в транскрипт
   без текста (только `signature`), а лента после ресинка собирается из транскрипта. Supervisor хранит текст
   thinking сам и подставляет его в `transcript.get`.
2. **Лимит вывода (32K режет ризонинг glm на xhigh).** Для незнакомых Claude Code моделей default 32000,
   потолок 128000; поднимает `CLAUDE_CODE_MAX_OUTPUT_TOKENS`. Настройка аккаунта: обычный лимит + лимит
   на высоком усилии (xhigh и выше) — адаптив под усилие сессии, степень задаётся в аккаунте.
3. **Список задач как в Claude Code Desktop.** В SDK-режиме Claude Code даёт TodoWrite/Task* новым моделям
   только с `CLAUDE_CODE_ENABLE_TODO_TOOLS=1`. Включение по аккаунту, поддержка `TaskCreate`/`TaskUpdate`
   в панели «Задачи», список над полем ввода.
4. **Усилие у z.ai.** `/v1/models` z.ai не отдаёт `capabilities.effort` → у всех glm пусто. Ручная настройка
   «поддерживает усилие» (аккаунт/модель); проверить, что Claude Code передаёт усилие незнакомым моделям
   (`ANTHROPIC_DEFAULT_*_MODEL_SUPPORTED_CAPABILITIES`).
5. **Usage как в Desktop.** Подключаемый на аккаунт (как ultracode): подписка Claude — лимиты 5 ч / неделя,
   z.ai — их квота. Сначала разведать источники данных.
