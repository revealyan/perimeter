## Параллельно

- **Dev-стек в docker:** изолированный supervisor + vite (свой HOME, демо-движок или тестовый ключ), порты
  только на loopback, доступ — «Порты» в самом Perimeter или `ssh -L`. Прод (`perimeter.service`) не трогать.
  Ручной CI-запуск: portable exe с любой ветки — для проверки Electron-части.
- **Новый сервер «без лишних движений»** (`docs/design/onboarding.md`): IP + пароль root → приложение само
  ставит ключ, пользователя службы без sudo, пакеты, supervisor, браузер на сервере, rootless docker, ключ GitHub;
  затем аккаунт (с этого компьютера одной кнопкой) и проект. Плюс «Переезд с другого сервера».
  Сделано: шаг 1 — вход паролем → ключ приложения (23.11). Дальше — план установки и шаги под root (пакеты,
  браузер, rootless docker, ключ GitHub): проверять только на чистом сервере с root — большой VPS.
- **Переезд на большой VPS** 185.119.17.115 (10 ядер / 32 ГБ) — первым живым прогоном этого флоу; затем
  погасить Velohost.
