# Бэклог

Единый список задач. Решения и история — в `decisions.md`, кандидаты из референсов — в `gap-analysis.md`
(топ-9 и «быстрые S»). Сделанное отсюда убирается, в журнал решений — запись.

## Сейчас (порядок владельца, 2026-11-23)

1. **Лимит вывода (32K режет ризонинг glm на xhigh).** Для незнакомых Claude Code моделей default 32000,
   потолок 128000; поднимает `CLAUDE_CODE_MAX_OUTPUT_TOKENS`. Настройка аккаунта: обычный лимит + лимит
   на высоком усилии (xhigh и выше) — адаптив под усилие сессии, степень задаётся в аккаунте.
2. **Список задач как в Claude Code Desktop.** В SDK-режиме Claude Code даёт TodoWrite/Task* новым моделям
   только с `CLAUDE_CODE_ENABLE_TODO_TOOLS=1`. Включение по аккаунту, поддержка `TaskCreate`/`TaskUpdate`
   в панели «Задачи», список над полем ввода.
3. **Усилие у z.ai.** `/v1/models` z.ai не отдаёт `capabilities.effort` → у всех glm пусто. Ручная настройка
   «поддерживает усилие» (аккаунт/модель); проверить, что Claude Code передаёт усилие незнакомым моделям
   (`ANTHROPIC_DEFAULT_*_MODEL_SUPPORTED_CAPABILITIES`).
4. **Usage как в Desktop.** Подключаемый на аккаунт (как ultracode): подписка Claude — лимиты 5 ч / неделя,
   z.ai — их квота. Сначала разведать источники данных.
5. **Автокомпакт на сессию.** Порог/окно автокомпакта (glm — 400–600K, чтобы не жечь сессию) выбирать
   у сессии, умолчание — у аккаунта/модели. Сейчас только через «свои модели» аккаунта (`glm-5.4@400k` →
   `autoCompactWindow` при старте процесса).

## Параллельно

- **Dev-стек в docker:** изолированный supervisor + vite (свой HOME, демо-движок или тестовый ключ), порты
  только на loopback, доступ — «Порты» в самом Perimeter или `ssh -L`. Прод (`perimeter.service`) не трогать.
  Ручной CI-запуск: portable exe с любой ветки — для проверки Electron-части.
- **Новый сервер «без лишних движений»** (`docs/design/onboarding.md`): IP + пароль root → приложение само
  ставит ключ, пользователя службы без sudo, пакеты, supervisor, браузер на сервере, rootless docker, ключ GitHub;
  затем аккаунт (с этого компьютера одной кнопкой) и проект. Плюс «Переезд с другого сервера».
- **Переезд на большой VPS** 185.119.17.115 (10 ядер / 32 ГБ) — первым живым прогоном этого флоу; затем
  погасить Velohost.

## Потом

- **«Окружение»** (`docs/design/environment.md`): страница сред с `env.probe` (что есть, на что влияет, как
  поставить); обновление движка Claude Code отдельным слоем (`cli/<версия>` + current, каналы стабильный/fresh,
  откат); сервисы среды в docker (postgres/redis, порты в «Порты»); переменные проекта (шифрованно) → env сессий;
  MCP `env.service.*` для агентов.
- **Локальный supervisor переживает закрытие окна** (трей / отсоединение / служба Windows) и **ретрай портов**
  8791/8800 после EADDRINUSE.

- **Хранилище публичных ssh-ключей сред** в настройках подключения: увидеть/скопировать ключ среды
  (агентам — доступ на другие машины), сгенерировать, «разрешить вход с A на B» одной кнопкой.
- **Микро-редизайн** — ближе к Claude Code Desktop.
- **Вспомогательные панели** (Изменения, Терминал, Файлы, Браузер, Порты, Задачи в шапке сессии):
  переделать поведение как в Desktop, ненужные — отключать в настройках.
