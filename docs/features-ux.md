| # | Фича | Что в нашем UI | Данные |

| 1 | Лента сообщений | типографика, маркдаун (блоки/инлайн/жирный), пустые состояния, автоскролл с «к-scroll вниз» | 🖥 |

## UX-развилки раунда (решает владелец)

1. Мультиакк в сайдбаре: секции-аккаунты vs чипы при создании vs глобальный переключатель
2. Проекты: проект = папка на VPS (группировка сессий) vs метка vs без проектов
3. Создание сессии: сразу с дефолтами (как сейчас) vs модалка/строка запуска (папка+профиль+модель+режим)
4. Набор фич в раунд полировки: подтвердить/урезать таблицу выше
