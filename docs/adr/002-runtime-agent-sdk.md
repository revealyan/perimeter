# АДР 002: Supervisor на Node/TS с Agent SDK

- Статус: принято (2026-11-08)
- Развилка: ② рантайм supervisor

## Контекст

Supervisor должен управлять долгоживущими claude-процессами: кадры пользователя, control-канал (can_use_tool, interrupt), контрольные методы (setPermissionMode, rewindFiles, getContextUsage…), типизованные события. Варианты: Node+SDK; Go/Rust raw; TS raw.

## Решение

Node/TypeScript + `@anthropic-ai/claude-agent-sdk`. Одна сессия = один `query()` со стриминговым входом (`streamInput`), долгоживущий субпроцесс.

## Последствия

- Новая зависимость: SDK (поставляется со своим бинарем CLI; версия SDK пинует версию CLI — апгрейд отдельным шагом с прогоном на стенде).
- Протокол проводной — тот же stream-json (§2.7 recon.md): откат на raw-клиент (TS без SDK) возможен без смены архитектуры.
- Инвариант: события и контрольные вызовы, на которые опирается UI, определены в типах SDK; собственная обёртка поверх SDK — единственное место, зависящее от SDK (тест: мок SDK-событий → обёртка выдаёт наш протокол).
