# АДР 003: Протокол UI↔supervisor — WSS c JSON-кадрами

- Статус: принято (2026-11-08)
- Развилка: ④ протокол UI↔supervisor

## Контекст

Десктоп-UI (Electron/Tauri) на машине владельца, supervisor на VPS. Транспорт — SSH-порт-форвардинг (публичных портов нет, TLS опционален внутри туннеля). Нужны: поток событий сессий вниз, команды вверх, догон после реконнекта, запросы-ответы (карточки разрешений).

## Решение

Один WebSocket (wss внутри туннеля), кадры — JSON-объекты с общей шапкой `{v, id?, type, sessionId?, seq, ts}`. Направления: `event:*` (supervisor→UI, монотонный `seq` на сессию), `cmd:*` (UI→supervisor, `id`→`ack/err` ответ). Реконнект: UI шлёт `cmd:resume {sessionId, lastSeq}` → supervisor ретранслирует пропущенное из своего ринг-буфера; глубже ринг-буфера — ресинк из транскрипта.

## Последствия

- Инвариант: `seq` монотонный без дыр на сессию (тест: разрыв сокета на N сек → resume → лента байт-в-байт как без разрыва).
- Разрешения — `cmd:permission.respond {requestId, behavior, updatedInput?}` к событию `event:permission.request`; таймаут карточки = таймаут хода.
- Схема кадров — код в пакете `protocol` (общий для supervisor и UI), поле `v` для версионирования.
