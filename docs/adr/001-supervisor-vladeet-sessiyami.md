# АДР 001: Supervisor владеет процессами claude

- Статус: принято (2026-11-08)
- Развилка: ① модель процессов на VPS

## Контекст

Нужна живучесть сессий при обрывах UI/SSH и полный программный контроль (карточки разрешений, interrupt, метрики). Варианты: свой supervisor с детьми-claude; встроенный daemon (`--bg`/`attach`, приватные сокеты roster.json); tmux + send-keys (скрейпинг).

## Решение

Свой supervisor-демон (systemd-юнит) на VPS. Каждая сессия = долгоживущий процесс `claude -p --input-format stream-json --output-format stream-json --verbose …`, запущенный и управляемый supervisor'ом. Восстановление после падения supervisor — `--resume <session-id>` по транскрипту на диске.

## Последствия

- Вся коммуникация — по документированным поверхностям (stream-json §2.7 recon.md); ни приватных сокетов daemon, ни tmux-скрейпинга.
- tmux остаётся опциональным ручным слоем для отладки (`claude attach`), не несёт семантики.
- Инвариант: смерть supervisor не теряет сессию — транскрипт + session-id достаточно для полного восстановления ленты и продолжения (тест: kill -9 supervisor → рестарт → лента идентична).
