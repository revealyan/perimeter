# Perimeter

**Десктоп-пульт к Claude Code: сессии живут на твоих серверах, переживают обрывы и ждут тебя.**

Назван в честь «Периметра» — системы, которая несёт дежурство автономно, даже когда связь с командным пунктом потеряна. Это и есть главная идея: закрываешь ноутбук — агенты продолжают работать на сервере; открываешь — видишь, кто дошёл до конца, а кто ждёт твоего решения.

Полностью своё решение: официальный Agent SDK как клиент протокола CLI, собственный supervisor и собственный клиент. Готовые альтернативы (Happy, claude-code-ui, opcode, crystal) изучены как справочники, но ни строчки оттуда не взято.

```
┌──────────────┐  wss (ssh-туннель)  ┌──────────────────────┐   SDK / stream-json   ┌─────────────┐
│  Electron    │ ───────────────────▶ │  supervisor (VPS)    │ ────────────────────▶ │ процессы    │
│  Perimeter   │ ◀─────────────────── │  systemd, 127.0.0.1  │ ◀──────────────────── │ Claude Code │
└──────────────┘                     └──────────────────────┘                       └─────────────┘
       │                                        │
       │  локальная среда: свой supervisor      │  транскрипты ~/.claude/projects/**
       └────────────────────────────────────────┘  (ресинк ленты после обрыва)
```

## Что внутри

- **Обе среды сразу.** «Этот компьютер» и сколько угодно VPS в одном окне; общий «Ждут тебя · N» — кто просит разрешения, кто задал вопрос.
- **Живучесть.** `kill -9` supervisor'а → systemd поднимает → реестр восстанавливается → сессии возрождаются через `--resume`, лента — ресинком из транскрипта. Обрыв связи → догон по `seq` без потерь.
- **Панели, как у Claude Code Desktop.** Терминал (PTY на сервере), файлы с git-статусом, удалённый браузер прямо на VPS, порты с автопробросом как в VS Code Remote SSH.
- **Перенос сессий между средами.** История и настройки переезжают ПК ↔ VPS целиком, незакоммиченные правки — патчем на совпавший коммит.
- **Аккаунты и модели.** Несколько аккаунтов (Claude OAuth, шлюзы вроде z.ai с ключом), модели и усилие на сессию, пул тёплых процессов.
- **Сквозные сабагенты.** Делегирование подзадач воркерам на других аккаунтах — воркер живёт настоящей сессией со своей лентой, в git-проектах — в собственном worktree.
- **Хранилище проектов.** Проект = имя → папка в каждой среде, синк по имени, дежурные «Ждут тебя» по всем подключениям.

## Быстрый старт

```bash
git clone https://github.com/revealyan/perimeter.git
cd perimeter
npm install
npm run desktop          # окно; локальный supervisor на :8791 поднимется сам
```

Подключение VPS: «+ Подключение» → адрес и ssh-ключ → в настройках блока «Supervisor на сервере» нажать **«Установить»** — приложение само поставит на сервер Node, Claude Code и systemd-службу (как VS Code Remote SSH ставит свой сервер). Наружу на VPS не торчит ничего: supervisor слушает только loopback.

Требований почти нет: Claude Code CLI и Node приезжают внутри установки, ssh-клиент не нужен (свой). Системный `git` — опционально, для git-фича (статус, патчи, worktree).

| Команда | Что |
|---|---|
| `npm test` | 599 тестов: протокол, движок, WSS-инварианты, живые e2e (kill -9 → ресинк) |
| `npm run typecheck` | типы всего монорепо |
| `npm run desktop` | vite + Electron |
| `npm run supervisor` | голый supervisor на 127.0.0.1:8790 |
| `npm run killtest` | живой e2e живучести |
| `npm run server:install -- <подкл.> status\|install\|rollback` | supervisor на VPS из терминала |

## Монорепо

| Пакет | Что это |
|---|---|
| `packages/protocol` | схема кадров UI ↔ supervisor (zod, единственный источник типов) |
| `packages/supervisor` | демон: менеджер сессий, WSS, панели, респаун, персистентность |
| `apps/desktop` | Electron + React-клиент |

Инварианты — тестами (см. `docs/p0-design.md`): монотонный `seq` без дыр, доставка разрешений после обрыва, игнор неизвестных кадров (прямая совместимость), только loopback.
